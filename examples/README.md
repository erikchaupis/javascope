# JavaScope demo workspace

Open `workspace/` in VS Code to try JavaScope end to end:

- `src/com/acme/OrderServiceUnformatted.java` — run **JavaScope: Format Java
  Document** to see the Eclipse JDT formatter at work.
- `webapp/users.jsp` — run **JavaScope: Format JSP Document** to see JSP
  structural formatting with the scriptlet Java formatted by JDT.
- The committed `.javascope/settings.json` activates the Eclipse Light scheme.
- Try **JavaScope: Open Administration** to explore themes, profiles and
  toggles. Switch the theme to *IntelliJ Darcula* and watch the Java editor
  colors change while the rest of VS Code stays as-is.
